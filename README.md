Детектирование дорожной разметки в реальном времени на основе преобразования Хафа.
Алгоритм находит левую и правую линии полосы и закрашивает её зелёным.

Хорошо работает при:

дневном освещении,
чёткой разметке,
прямой или слабоизогнутой дороге.

Может терять линии при резких поворотах, плохом освещении или отсутствии разметки.

Для запуска устанавливаем библиотеки: pip install opencv-python numpy

Запускаем два файла main.py и lanes.py

Берем видео из папки dataset. 

Добавляем видео в папку проекта и называем его "road.mp4"

Для тестирование кода по фото нужно заменить  video = cv.VideoCapture("road.mp4") на video = cv.VideoCapture("road.jpg") и положить фото с названием "road.jpg"

Нейросетевые модели решают эту проблему потому что обучены на тысячах примеров включая перекрёстки.
