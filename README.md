# 🚗 Road Lane Detection

Детектирование дорожной разметки в реальном времени на основе преобразования Хафа.  
Алгоритм находит левую и правую линии полосы и закрашивает её зелёным.


---

## Как это работает

Каждый кадр проходит через цепочку обработки:

```
Кадр → Grayscale → Gaussian Blur → Canny → Маска ROI → Hough Lines → Усреднение → Визуализация
```

- **Canny** — выделяет границы объектов на изображении
- **Маска ROI** — отсекает всё кроме области дороги
- **HoughLinesP** — находит отрезки в области интереса
- **История кадров** — стабилизирует линии при временной потере разметки

## Установка

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Snowman111111/road-detection.git
cd road-detection
```

### 2. Установи зависимости

Нужен Python 3.8 или выше. Установи библиотеки:

```bash
pip install opencv-python numpy
```

### 3. Добавь видео

Положи видеофайл в папку проекта и назови его `road.mp4`,  
или измени путь в `main.py`:

```python
video = cv.VideoCapture("road.mp4")  # ← укажи свой файл
```

Тестовые видео из папки `dataset/` тоже подойдут:

```python
video = cv.VideoCapture("dataset/road2.mp4")
```
**Тестирование на фото:**  
Если хочешь проверить алгоритм на одном изображении — положи фото в папку проекта с названием `road.jpg` и замени строку в `main.py`:

```python
video = cv.VideoCapture("road.jpg")  # ← вместо road.mp4
```

## Ограничения

Алгоритм хорошо работает при:
- дневном освещении
- чёткой разметке
- прямой или слабоизогнутой дороге

Может терять линии при резких поворотах, плохом освещении или отсутствии разметки.
